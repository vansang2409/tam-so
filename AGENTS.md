# Tâm Sở — autonomous development

For autonomous Đi Chùa work, read `docs/di-chua-autonomous-team.md` and `docs/di-chua-backlog.md` before selecting work. These files supplement the user's global instructions. Current source and current user requests take precedence over old plans and historical completion counts.

The user authorizes a coordinated team for research, product prioritization, development, QA and independent review of Đi Chùa. Delegate independent research/QA/review to subagents when available. Keep one coordinator and one writer per file; do not let multiple agents control the browser or edit the same files simultaneously. Use the inherited model; do not silently choose paid services or different models.

Preserve the existing uncommitted work. Do not reset, clean, stash, commit, push, merge, deploy or mutate hosted data without corresponding user authorization. Local reversible implementation and testing are authorized. Never read or print secret values from `.env.local`.
